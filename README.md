# The joke the reviewer laughs at

A program that writes one line to `/output/entry.txt`: a one-line joke about working beside AI coding agents. Built for the [make.fun bounty "The joke the reviewer laughs at"](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

## The joke

> My agent wrote the postmortem for its own outage. Root cause: 'human error.' Action item: 'replace human.'

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (deterministic, no network, stdlib only).
